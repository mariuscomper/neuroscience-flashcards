2. **Cloze Deletion**
   - Fill-in-the-blank

3. **Reverse Mode**
   - Swaps Q ↔ A

4. **Multiple Choice**

5. **Free Recall**
   - Type full answer
   - Fuzzy matching for grading
   - Most challenging mode

**Smart Recommendations:**
- "For new cards → Classic mode"

- "Before exam → Multiple choice"

### 🔍 Smart Search (NEW!)

**Advanced Search Capabilities:**

1. **Fuzzy Search** (typo-tolerant):
   - "glutmat" → finds "glutamate"
   - "fotoreceptors" → finds "photoreceptors"
   - Levenshtein distance algorithm

2. **Semantic Search** (concept-aware):
   - "inhibitor" → finds GABA, glycine, hyperpolarization, IPSP
   - "excitatory" → finds glutamate, acetylcholine, depolarization, EPSP
   - Pre-defined semantic mappings

3. **Boolean Operators**:
   - "glutamate AND receptors"
   - "GABA OR glycine"

4. **Advanced Filters**:
   - Module filter (M1-M6)
   - Status filter (new/learning/mastered/difficult)
   - Combined: "GABA + M3 + difficult + not reviewed recently"

5. **Auto-Suggestions**:
   - Type "glut" → suggests "glutamate", "glutamine"
   - **Related terms**: searched "axon" → "See also: myelin, saltatory conduction"

6. **Smart Results**:
   - Highlight matches in text
   - Show context
   - Sort by relevance
   - "Found in: 15 cards, 3 diagrams, 8 graph nodes"
