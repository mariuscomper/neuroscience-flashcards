# Neuroscience Flashcards - UBB

A comprehensive spaced repetition flashcard application for neuroscience studies, covering all major topics from the UBB Neuroscience course.

## Features

- **812 comprehensive flashcards** across 6 modules
- **Spaced repetition algorithm** (SM-2 inspired) for optimal learning
- **Progress tracking** with persistent localStorage
- **Mark difficult cards** for focused review
- **Export/Import** progress for backup
- **Search functionality** to find specific topics
- **Progress badges** showing repetition counts

## Modules Covered

- **M1**: Perspectivă istorică (123 cards)
- **M2**: Neuroni & Celule Gliale (135 cards)
- **M3**: Semnalizare Sinaptică (133 cards)
- **M4**: Neuroanatomie (156 cards)
- **M5**: Dezvoltare SN (117 cards)
- **M6**: Văzul (146 cards)

## Usage

Simply open `neurostiinte-improved.html` in your web browser. No installation or server required.

## Learning System

- Rate each card from 0-5 based on how well you knew the answer
- Cards with 3+ correct repetitions are considered mastered
- Rating below 3 resets progress for that card
- Progress is automatically saved in your browser

## Technical Details

- Built with React (via CDN)
- Pure client-side application
- Content-based hash IDs for stable progress tracking
- Responsive design for mobile and desktop
